# 🐳 دليل تشغيل منصة عرب أورا باستخدام دوكر (Docker & Docker Compose)

يوفر هذا الدليل طريقة تشغيل منصة **عرب أورا (Arab Aura)** كحاويات مدمجة معزولة بنقرة واحدة، لتشغيل الفرونت إند والباك إند وقاعدة البيانات معاً في بيئة إنتاجية جاهزة.

---

## 🏗️ البنية المعمارية للحاويات (Docker Architecture)

```
                    ┌─────────────────────────┐
                    │     المتصفح / العميل    │
                    │  http://localhost:80    │
                    └────────────┬────────────┘
                                 │
                     ┌───────────▼───────────┐
                     │  حاوية Frontend       │
                     │  Nginx 1.27 + React   │
                     │  (منفذ 80 و 5173)     │
                     └───────────┬───────────┘
                                 │
                    /api/*       │   Reverse Proxy
                                 ▼
                     ┌───────────────────────┐
                     │  حاوية Backend        │
                     │  Node.js 20 Express   │
                     │  (منفذ 8000)          │
                     └───────────┬───────────┘
                                 │
                                 ▼
                     ┌───────────────────────┐
                     │  قاعدة بيانات مونجو   │
                     │  MongoDB Atlas Cloud  │
                     │  أو حاوية Mongo محلي  │
                     └───────────────────────┘
```

---

## 🚀 التشغيل المباشر في ثوانٍ معدودة

### 1. تشغيل المنصة كاملة (بالاتصال السحابي بـ MongoDB Atlas الافتراضي):
```bash
docker compose up --build -d
```
- تفتح المنصة تلقائياً على:
  - **الواجهة الرئيسية:** [http://localhost](http://localhost) أو [http://localhost:5173](http://localhost:5173)
  - **واجهة الـ API والـ Health Check:** [http://localhost:8000/api/health](http://localhost:8000/api/health)

### 2. ملء البيانات التجريبية والحسابات الأولية داخل الحاوية:
```bash
docker compose exec backend npm run seed
```

### 3. متابعة السجلات المباشرة (Live Logs):
```bash
docker compose logs -f
```

### 4. إيقاف الحاويات:
```bash
docker compose down
```

## 📴 التشغيل أوفلاين (بدون إنترنت إطلاقاً)
إذا كنت تجري عرضاً تقديمياً أو مناقشة تخرج دون اتصال بالإنترنت، يمكنك تفعيل ملف الحاويات المحلي:
```bash
docker compose --profile offline up --build -d
```
سيقوم هذا الأمر بتشغيل حاوية MongoDB محلية خاصة بالمشروع على المنفذ `27017`.
